# Wood-Biz — многоязычная лендинг-страница-заглушка (wood-biz.com)

Лёгкая статическая страница без фреймворков: чистые HTML5, CSS3 и Vanilla JS.

## Языки

| Код | Язык        | Кнопка в переключателе |
|-----|-------------|------------------------|
| RU  | Русский     | RU                     |
| EN  | English     | EN                     |
| KO  | 한국어      | KO                     |
| ZH  | 简体中文    | 中文                   |

Выбранная язык сохраняется в `localStorage` и автоматически определяется по языку браузера при первом визите. Атрибут `<html lang>` обновляется (`ru / en / ko / zh-CN`).

## Структура

- `index.html` — разметка: Header (логотип + переключатель языков), Hero, блок услуг (4 пункта), CTA-секция с формой, Footer с контактами.
- `styles.css` — минималистичный дизайн: белые/серые тона + тёмно-зелёный акцент (#1b4332), адаптивная сетка (4 → 2 → 1 колонка).
- `app.js` — словарь переводов `I18N`, переключение языка, валидация формы (email/телефон/обязательные поля), подтверждение отправки.

## Форма

Поля: имя, email, телефон, сообщение. Валидация выполняется на `blur`, при вводе и при отправке; сообщения об ошибках локализованы. Отправка сейчас симулируется на клиенте — для реального бэкенда замените блок в `initForm()` (помечен комментарием) на `fetch()` с POST на ваш эндпоинт.

## SEO

Базовые мета-теги: `title`, `description` (локализованы), `keywords`, `robots`, `canonical`, Open Graph, Twitter Card, JSON-LD (`Organization`), инлайн favicon без дополнительного запроса.

## Запуск

Достаточно открыть `index.html` в браузере либо отдать статику любым сервером:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```
