# Wood-Biz — многоязычная страница-витрина (wood-biz.com)

Статическая страница без фреймворков: HTML5, CSS3, Vanilla JS.
Задача страницы — коротко описать род деятельности компании, без призывов к действию.

## Языки

| Код | Язык      | Кнопка |
|-----|-----------|--------|
| RU  | Русский   | RU     |
| EN  | English   | EN     |
| KO  | 한국어     | KO     |
| ZH  | 简体中文   | 中文    |

Выбранный язык сохраняется в `localStorage`, при первом визите определяется по языку браузера.
Атрибут `<html lang>` обновляется (`ru / en / ko / zh-CN`).

## Структура

- `index.html` — Header (логотип + переключатель языков), Hero, блок из четырёх услуг, секция контактов с формой, Footer.
- `styles.css` — белые/серые тона, тёмно-зелёный акцент (#1b4332), адаптивная сетка услуг (4 → 2 → 1 колонка).
- `app.js` — словарь переводов `I18N`, переключение языка, подключение iframe Zoho Forms, год в футере.

## Форма

Форма — iframe Zoho Forms, ссылка задаётся в `index.html` в атрибуте `data-src` у `#zoho-form`.
Пока `data-src` пуст, iframe не загружается: посетитель видит блок с адресом `info@wood-biz.com`.
Ложного подтверждения отправки нет — оно удалено.

В `app.js` остался безопасный обработчик `initForm()` для случая, если форму вернут как нативный `<form>`:
он отправляет данные только при заданном `data-endpoint`, иначе показывает сообщение с email.

## SEO

`title`, `description` (локализованы), `keywords`, `robots`, `canonical`, Open Graph, Twitter Card,
JSON-LD (`Organization`), инлайн favicon без дополнительного запроса.

## Запуск

Открыть `index.html` в браузере или отдать статику любым сервером:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```
